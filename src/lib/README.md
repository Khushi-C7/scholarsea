# lib

Infrastructure and integrations.

- `db/` — Prisma client and data-access helpers.
- `ai/` — provider abstraction (OpenAI-compatible + adapters).
- `documents/` — PDF extraction, URL ingestion, metadata parsing.
- `search/` — academic discovery sources (e.g. arXiv).
- `auth/` — authentication and authorization utilities.
- `validation/` — shared Zod schemas and request validation.
- `export/` — Markdown / JSON / BibTeX export formatting.
